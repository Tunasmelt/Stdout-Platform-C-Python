# Screenshots Directory

This directory contains project screenshots for the README.md file.

## Required Screenshots

As the Stdout platform develops, add the following screenshots:

1. **dashboard.png** - Main student dashboard showing progress, available lessons, and recommended content
2. **lesson-view.png** - Interactive lesson view with Monaco code editor, real-time execution, and lesson content  
3. **assessment.png** - Initial assessment quiz and self-report for personalized learning paths
4. **teacher-cms.png** - Teacher content management system for creating and managing lessons
5. **offline-mode.png** - Offline capability indicator and local queue management

## Guidelines

- Use consistent dimensions (recommended: 1200x800px)
- Show realistic data and content
- Ensure text is readable
- Use light mode for consistency
- Capture key features and UI elements
- Keep file sizes reasonable (under 500KB each)

## Adding Screenshots

1. Capture screenshots using your preferred tool
2. Name them according to the list above
3. Place them in this directory
4. Update the README.md references if using different filenames
